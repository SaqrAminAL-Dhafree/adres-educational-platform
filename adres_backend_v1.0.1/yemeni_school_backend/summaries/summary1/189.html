٤ : ٣ حل تمارين ومسائل الكتاب المدرسي ص١٨٧
على النسب المثلثية للزوايا ٣٠°، ٦٠°، ٤٥°

[١] أوجد قيمة كل مما يلي :
أ) جتا ٤٥° جتا ٤٥° ، ب) جا ٣٠° جتا ٦٠° + جتا ٣٠° جا ٦٠°
جـ) ٣ ظا² ٣٠° + جا ٣٠° ، د) جتا² ٦٠° جا² ٦٠°
هـ) \( \frac{1 - \text{ظا } ٦٠^\circ}{1 + \text{ظا } ٤٥^\circ} \)
* الحل *
أ) \( \frac{1}{\sqrt{2}} \times \frac{1}{\sqrt{2}} = \frac{1}{2} \)

ب) \( \frac{1}{2} \times \frac{1}{2} + \frac{\sqrt{3}}{2} \times \frac{\sqrt{3}}{2} = \frac{1}{4} + \frac{3}{4} = \frac{4}{4} = 1 \)

جـ) \( 3 \times (\frac{1}{\sqrt{3}})^2 + \frac{1}{2} = 3 \times \frac{1}{3} + \frac{1}{2} = 1 + \frac{1}{2} = 1.5 \)

د) \( (\frac{1}{2})^2 \times (\frac{\sqrt{3}}{2})^2 = \frac{1}{4} \times \frac{3}{4} = \frac{3}{16} \)

هـ) \( \frac{1 - \sqrt{3}}{1 + (1)} = \frac{1 - \sqrt{3}}{2} \)
[٢] أثبت أن : \( \frac{1}{1 + \text{جا } ٣٠^\circ} + \frac{1}{1 - \text{جا } ٣٠^\circ} = \frac{2}{\text{جتا}^2 ٣٠^\circ} \)
* الحل *
الطرف الأيمن = \( \frac{1}{1 + \frac{1}{2}} + \frac{1}{1 - \frac{1}{2}} = \frac{1}{\frac{3}{2}} + \frac{1}{\frac{1}{2}} = \frac{2}{3} + 2 = \frac{2+6}{3} = \frac{8}{3} \) (١)
الطرف الأيسر = \( \frac{2}{(\frac{\sqrt{3}}{2})^2} = \frac{2}{\frac{3}{4}} = \frac{8}{3} \) (٢)
من (١)، (٢) الطرفان متساويان #
[٥] أثبت أن جا ٢س = \( \frac{2 \text{ ظا س}}{1 + \text{ ظا}^2 \text{ س}} \)، حيث ق(س) = ٣٠°
* الحل *
الطرف الأيمن = جا ٢س = جا ٢ × ٣٠° = جا ٦٠° = \( \frac{\sqrt{3}}{2} \) --(١)
الطرف الأيسر = \( \frac{2 \text{ ظا } ٣٠^\circ}{1 + \text{ ظا}^2 ٣٠^\circ} = \frac{2 \times \frac{1}{\sqrt{3}}}{1 + (\frac{1}{\sqrt{3}})^2} = \frac{\frac{2}{\sqrt{3}}}{1 + \frac{1}{3}} = \frac{\frac{2}{\sqrt{3}}}{\frac{4}{3}} \)
الطرف الأيسر = \( \frac{2}{\sqrt{3}} \times \frac{3}{4} = \frac{3}{2\sqrt{3}} \)
بإنطاق المقام: \( \frac{3}{2\sqrt{3}} \times \frac{\sqrt{3}}{\sqrt{3}} = \frac{3\sqrt{3}}{2 \times 3} = \frac{\sqrt{3}}{2} \) --(٢)
من (١)، (٢) الطرفان متساويان #
