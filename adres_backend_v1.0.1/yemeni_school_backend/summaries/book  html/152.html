التحقق :
ثمن المجلة + ثمن الكتاب = ٢٧ + ٤٨ = ٧٥ ريالاً .
ثمن الكتاب − ثمن المجلة = ٤٨ − ٢٧ = ٢١ ريالاً .
( ج ) نفرض أن عرض المستطيل = س
∴ طول المستطيل = س + ٧
محيط المستطيل = ٢ ( الطول + العرض )
٧٤ = ٢ ( س + ٧ + س )
٧٤ = ٢ ( ٢س + ٧ )
٧٤ = ٤س + ١٤
( بطرح العدد ١٤ من الطرفين )
٤س = ٧٤ − ١٤
٤س = ٦٠
( بقسمة الطرفين على العدد ٤ )
س = ١٥
∴ عرض المستطيل = ١٥ سم
طول المستطيل = ١٥ + ٧ = ٢٢ سم
التحقق : تحقق بنفسك من صحة الحل .
مثال (٢)
اشترى عادل عدداً من اللعب لأطفاله بثمن إجمالي قدره ١٢٠٠ ريال ، فإذا خُفِّض ثمن اللعبة بمقدار ١٠ ريالات لزاد عدد اللعب التي اشتراها بمقدار ٤ لعب ، فأوجد ثمن اللعبة قبل التخفيض .
