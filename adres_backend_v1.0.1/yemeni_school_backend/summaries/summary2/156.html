∴ عدد اللعب قبل التخفيض + ٤ = عدد اللعب بعد التخفيض
١٢٠٠ س + ٤ = ١٢٠٠ س − ١٠

١٢٠٠ س − ١٠ = ١٢٠٠ + ٤س س
( حاصل ضرب الطرفين = حاصل ضرب الوسطين )
١٢٠٠ س = ( س − ١٠ ) ( ١٢٠٠ + ٤س )
( بطرح ١٢٠٠ س من الطرفين )

( بقسمة الطرفين على العدد ٤ )
٠ = س² − ١٠س − ٣٠٠
